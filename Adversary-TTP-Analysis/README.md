# Adversary TTP Analysis

Bu qovluqda kiberhücumların təhlili, hücumçuların istifadə etdiyi Taktika, Texnika və Prosedurların (TTP) araşdırılması üzrə hazırlanmış hesabatlar və texniki qeydlər yerləşdirilir.
Hər bir araşdırmada əldə olunan nəticələr, istifadə edilən hücum metodları, texniki sübutlar və təhlükəsizlik baxımından əhəmiyyətli müşahidələr sənədləşdirilir.

**Qovluğun məqsədi:**
- Hücum metodlarını və TTP-ləri təhlil etmək.
- Hücum mərhələlərini sənədləşdirmək.
- MITRE ATT&CK çərçivəsi ilə əlaqələndirmə aparmaq.
- Aşkar edilmiş zəiflikləri və təhlükəsizlik risklərini qiymətləndirmək.
- Aşkarlama və müdafiə imkanlarını araşdırmaq.

Hesabatların strukturu araşdırmanın xüsusiyyətlərinə və əldə olunan texniki sübutlara uyğun olaraq dəyişə bilər.
